# Reverse Linked-Node Order by Iteration and Recursion
> Google · Other · easy · Pattern: Linked List
> Source: https://prachub.com/interview-questions/reverse-linked-node-order-by-iteration-and-recursion

### Problem

Reverse a singly linked list and return the reversed chain's head. Preserve the supplied ListNode pointer interface with val and next fields; example brackets display chain values only.

```cpp
ListNode* reverseList(ListNode* head);
```

### Examples

```text
Input chain: [6,-1,4]
Output chain: [4,-1,6]
```

```text
Input chain: []
Output chain: []
```

### Constraints

- There are between 0 and 5000 nodes.
- Values lie between -5000 and 5000.

### Optional follow-up

Provide both an iterative and a recursive reversal.
