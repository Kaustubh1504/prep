# Compute shortest paths with blocked nodes
> Google · Technical Screen · medium · Pattern: Shortest Path, Graph BFS / DFS
> Source: https://prachub.com/interview-questions/compute-shortest-paths-with-blocked-nodes

给一个图， 图上有node， 就一个给定node， 问它到每个node最短距离。有些node不accessible。

<details><summary>Hints (spoiler)</summary>

1. Treat blocked nodes as removed before BFS.
2. For directed graphs, only add the given edge direction.
