# Generate the One-Based Sequence of Ugly Numbers
> Google · Other · medium · Pattern: Math / Number Theory
> Source: https://prachub.com/interview-questions/generate-the-one-based-sequence-of-ugly-numbers

### Problem

Return the nth positive integer whose prime factors are limited to 2, 3 and 5. The first such integer is 1. Preserve the original int nthUglyNumber(int n) interface.

```cpp
int nthUglyNumber(int n);
```

### Examples

```text
n = 12 -> 16
n = 2 -> 2
```

### Constraints

- 1 <= n <= 1690.
