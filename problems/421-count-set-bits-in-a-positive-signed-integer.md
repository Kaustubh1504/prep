# Count Set Bits in a Positive Signed Integer
> Google · Other · easy · Pattern: Bit Manipulation
> Source: https://prachub.com/interview-questions/count-set-bits-in-a-positive-signed-integer

### Problem

Return the number of set bits in the binary representation of a positive integer n, also called its Hamming weight.

```cpp
int hammingWeight(int n);
```

### Examples

```text
Input: n = 42
Output: 3
```

Its binary spelling is 101010.

```text
Input: n = 1024
Output: 1
```

### Constraints

- `1 <= n <= 2147483647`.
