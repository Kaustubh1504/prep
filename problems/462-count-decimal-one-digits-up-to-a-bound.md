# Count Decimal One Digits up to a Bound
> Google · Other · hard · Pattern: Math / Number Theory
> Source: https://prachub.com/interview-questions/count-decimal-one-digits-up-to-a-bound

### Problem

Count all appearances of decimal digit 1 in the ordinary spellings of integers from 0 through n, inclusive. Count occurrences, not merely how many numbers contain a 1.

```cpp
int countDigitOne(int n);
```

### Examples

```text
n = 20 -> 12
n = 101 -> 23
```

### Constraints

- 0 <= n <= 1000000000.
