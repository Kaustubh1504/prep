# Detect Whether Any Integer Value Repeats
> Google · Other · easy · Pattern: Hashing / Counting
> Source: https://prachub.com/interview-questions/detect-whether-any-integer-value-repeats

### Problem

Return true if any integer value appears at least twice in nums. Return false when all values are distinct. Repeated positions need not be adjacent.

```cpp
bool containsDuplicate(vector<int>& nums);
```

### Examples

```text
Input: nums = [8,-1,3,8]
Output: true
```

```text
Input: nums = [0,4,-2]
Output: false
```

### Constraints

- Length is between 1 and 100000.
- Values lie between -1000000000 and 1000000000.
