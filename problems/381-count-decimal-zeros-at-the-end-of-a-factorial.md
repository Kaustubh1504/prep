# Count Decimal Zeros at the End of a Factorial
> Google · Other · medium · Pattern: Math / Number Theory
> Source: https://prachub.com/interview-questions/count-decimal-zeros-at-the-end-of-a-factorial

### Problem

Return the number of trailing decimal zeros in `n!`, the factorial of `n`. Use the convention `0! = 1`.

```cpp
int trailingZeroes(int n);
```

### Examples

```text
Input: n = 25
Output: 6
```

```text
Input: n = 100
Output: 24
```

### Constraints

- `0 <= n <= 10000`.
