# Recognize Powers of Three without Iteration
> Google · Other · easy · Pattern: Math / Number Theory
> Source: https://prachub.com/interview-questions/recognize-powers-of-three-without-iteration

### Problem

Return whether signed integer n is 3 raised to a nonnegative integer power.

```cpp
bool isPowerOfThree(int n);
```

### Examples

```text
n = 81 -> true
n = 45 -> false
```

### Constraints

- n spans the signed 32-bit domain.

### Optional follow-up

Can you solve it without loops or recursion?
